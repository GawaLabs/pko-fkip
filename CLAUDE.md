# PKO FKIP Universitas Tadulako

## Project

Frontend-only landing page for Program Studi Pendidikan Kepelatihan
Olahraga FKIP Universitas Tadulako.

## Stack

- Angular
- TypeScript
- Tailwind CSS
- Native CSS Scroll-Driven Animations
- Responsive design

## Language

All user-facing content must be in Bahasa Indonesia.

Technical code identifiers may use English.

## Design Direction

Sports + Academic + Modern + Editorial.

Avoid:
- Generic university template
- Excessive gradients
- Excessive glassmorphism
- Excessive rounded cards
- Excessive shadows
- Excessive animations

Prefer:
- Large typography
- Editorial layouts
- Strong sports imagery
- Asymmetric grids
- Bold section transitions
- Strong visual hierarchy

## Architecture

Keep UI components reusable.

Keep static content in:
src/app/data/

Do not introduce:
- Backend
- API
- Database
- Authentication
- CMS

## Important

Do not fabricate official institutional data.

Use placeholders when official data is unavailable.

Always inspect existing files before modifying them.
Reuse existing project configuration whenever possible.
